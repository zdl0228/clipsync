# ClipSync — 跨平台局域网剪贴板同步

ClipSync 是一个**免费、开源、无需服务器和账号**的跨平台剪贴板同步 + 文件发送工具，支持 **macOS 和 Windows**。

把两台（或多台）电脑连到同一个局域网，复制的内容会自动同步到其他设备；还能一键把文件、文件夹发送到目标设备。所有数据只在你的局域网内传输，不经过任何第三方服务器，隐私安全。

## ✨ 功能特性

- 🔄 **剪贴板自动同步**：复制文本、图片，自动同步到已连接的设备
- 📁 **文件 / 文件夹发送**：托盘菜单或拖拽即可发送文件到目标设备
- 🖥️ **跨平台**：macOS + Windows 双平台支持
- 🔐 **局域网加密直连**：数据仅在本地网络传输，不依赖外部服务器
- 🛎️ **系统托盘常驻**：常驻菜单栏，不打扰日常使用
- ⚡ **开机自启**：默认开机自动启动（可在菜单中关闭）
- 🖱️ **右键发送**（Windows）：选中文件右键即可发送

## 📦 安装

### 直接下载
从 Releases 页面下载对应平台的安装包：
- **macOS**：`ClipSync.dmg`，打开后拖入"应用程序"即可
- **Windows**：`ClipSync.exe`

### 从源码构建
需要 Go 1.27+ 环境。

```bash
# macOS
go build -o ClipSync .

# Windows（交叉编译）
GOOS=windows GOARCH=amd64 go build -o ClipSync.exe .
```

## 🚀 使用方法

1. 在两台需要同步的设备上都安装并启动 ClipSync
2. 确认两台设备在**同一个局域网**（连同一个路由器/Wi-Fi）
3. 程序会自动发现并配对同网段设备，托盘菜单显示"已连接"
4. **配对密钥**：两台设备的 `config.json` 中 `token` 保持一致，才能加密连接

### 同步剪贴板
- 在任意设备复制文本或图片，其他已连接设备自动收到

### 发送文件
- 托盘菜单 → **发送文件到 ▸** → 选择目标设备 → 选择文件/文件夹
- 或直接把文件**拖到托盘图标**上，发送给所有已连接设备
- Windows 下可开启**右键发送**，选中文件右键菜单直接发送

## ⚙️ 配置

配置文件位于系统配置目录下的 `clipsync` 文件夹（`config.json`），可修改：
- `token`：配对密钥，多设备保持一致
- 开机自启、自动发现广播等可在托盘菜单中直接开关

## 🛠️ 技术栈

- 语言：**Go**
- 界面：系统托盘（[getlantern/systray](https://github.com/getlantern/systray)）
- 网络：局域网 UDP 广播自动发现 + TCP 数据传输
- 剪贴板：macOS 原生 + Windows API
